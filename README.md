# Python File Organizer

A simple, lightweight Python script designed to automatically organize a cluttered folder (like your Downloads folder) by moving files into categorized subfolders based on their file extension.

## The Gap It Fills
Many users struggle with cluttered download folders, and existing software is often bloated or paid. This script provides a free, open-source, command-line solution for basic file management.

## How to Use
1. Clone this repository.
2. Open `organizer.py` and change the `FOLDER_TO_ORGANIZE` variable to the path of the folder you want to clean up.
3. Run the script using Python: `python organizer.py`

## Features
- Organizes Images, Documents, Videos, Music, and Archives.
- Lightweight and requires no external libraries (uses built-in `os` and `shutil`).
